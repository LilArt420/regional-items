# 🌏 Regional Items → now part of World Sync Extras

Regional Items moved into **[World Sync Extras](https://github.com/LilArt420/world-sync-extras)** 🗺️, so one install brings the regional items' names, descriptions and icons together with the rest of the World Sync content, and a Refine Master that makes refine tickets work.

In Ragnarok Offline: **Settings → Mods → Find Mods → world-sync-extras → Install**. If you still have `regional-items` installed, remove it once World Sync Extras is on: it carries the same tables.

This repository is archived and gets no more releases. The last standalone version, 2.0.1, is in [`regional-items/`](regional-items/).
